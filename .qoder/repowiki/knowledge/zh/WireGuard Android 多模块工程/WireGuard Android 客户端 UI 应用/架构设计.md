模块为 Android Application 工程（build.gradle.kts），以 `com.wireguard.android` 为命名空间，依赖 `:tunnel` 库和大量 AndroidX 组件。
- 入口：`Application.kt` 作为全局单例，负责初始化 RootShell、ToolsInstaller、DataStore 偏好、TunnelManager，并通过 `CompletableDeferred<Backend>` 异步选择 WgQuickBackend（内核模块）或 GoBackend。
- 分层结构：
  - `activity/`：基于 BaseActivity 的页面（MainActivity、SettingsActivity、TunnelCreatorActivity、LogViewerActivity、TvMainActivity、TunnelToggleActivity）。
  - `fragment/`：UI 片段（TunnelListFragment、TunnelDetailFragment、TunnelEditorFragment、AddTunnelsSheet 等），由 MainActivity 通过 FragmentManager 管理两栏布局。
  - `model/`：领域模型（ObservableTunnel、TunnelManager、TunnelComparator、ApplicationData），TunnelManager 继承 BaseObservable 并通过 DataBinding 暴露状态。
  - `configStore/`：ConfigStore 接口及 FileConfigStore 实现，将 .conf 文件映射为 wg-quick 格式。
  - `viewmodel/`：ConfigProxy、InterfaceProxy、PeerProxy 作为 DataBinding 的数据代理。
  - `databinding/`：自定义 BindingAdapter、ObservableKeyedArrayList 等数据绑定扩展。
  - `preference/`：自定义 Preference 组件（DonatePreference、KernelModuleEnablerPreference 等）。
  - `util/`：工具类（BiometricAuthenticator、ClipboardUtils、TunnelImporter、UserKnobs 等）。
  - `updater/`：应用更新检查与展示。
  - `widget/`：自定义 View（ToggleSwitch、NameInputFilter、TvCardView 等）。
- 依赖方向：Activity/Fragment → ViewModel/Model → ConfigStore/Backend；Application 作为全局容器通过 companion object 暴露单例访问。
- 资源：res/ 下按标准 Android 结构组织，包含多语言 strings.xml、夜间主题 values-night、TV 专用 layout-sw600dp、mipmap-* 图标等。
