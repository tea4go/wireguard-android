- 所有 Activity 继承 BaseActivity，Fragment 继承 BaseFragment，统一生命周期与行为基类。
- UI 状态通过继承 BaseObservable 的 Model（如 TunnelManager、ObservableTunnel）配合 @Bindable 注解与 DataBinding 双向绑定。
- 异步操作统一通过 applicationScope（Dispatchers.Main.immediate / Dispatchers.IO）+ withContext 切换线程，避免在主线程执行 IO。
- 用户偏好通过 UserKnobs 封装 DataStore Flow 读写，以 first() 获取初始值、onEach 监听变化。
- 错误信息集中通过 ErrorMessages 映射到字符串资源，避免硬编码提示文本。
- 配置文件以 .conf 后缀存储在 context.filesDir，通过 FileConfigStore 统一进行 create/load/save/delete/rename 操作。
