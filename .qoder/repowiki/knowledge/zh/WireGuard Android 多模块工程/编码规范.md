- 所有模块共用 gradle.properties 中的 wireguardVersionCode、wireguardVersionName、wireguardPackageName 作为版本与包名来源
- 插件与依赖版本通过 settings.gradle.kts 的 pluginManagement 与 dependencyResolutionManagement 统一管理，禁止子模块自行声明仓库
- tunnel 模块以 Android Library 形式暴露 API 并支持 Java 8+ 特性（desugaring），ui 模块通过 DataBinding + MVVM 组织界面逻辑
