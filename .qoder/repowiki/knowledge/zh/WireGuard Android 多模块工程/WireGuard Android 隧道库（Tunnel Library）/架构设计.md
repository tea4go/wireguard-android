模块采用分层设计：
- `com.wireguard.config` 层负责 wg-quick 配置文件解析，将 `[Interface]`/`[Peer]` 段解析为不可变的 `Config`、`Interface`、`Peer` 等模型，并通过 `BadConfigException`/`ParseException` 报告错误。
- `com.wireguard.crypto` 层提供 Curve25519 密钥对与 Key 类型，作为上层配置与后端的抽象。
- `com.wireguard.android.backend` 层定义 `Backend` 接口及两种实现：`GoBackend`（通过 JNI 调用 libwg-go.so，使用 wireguard-go userspace）和 `WgQuickBackend`（通过 RootShell 执行系统 wg-quick）。`GoBackend` 内部嵌套一个 `VpnService` 子类，通过 `android.net.VpnService.Builder` 建立 TUN 设备并管理路由/DNS。
- `com.wireguard.android.util` 提供 `RootShell`、`SharedLibraryLoader`、`ToolsInstaller` 等工具类。
- 原生层位于 `tools/libwg-go/`，通过 CGo 暴露 `wgTurnOn/wgTurnOff/wgGetSocketV4/V6/wgGetConfig/wgVersion` 等导出函数，由 Java 侧 `native` 方法调用；CMake 构建产出 `libwg-go.so`、`libwg.so`、`libwg-quick.so` 三个目标。
- 依赖方向单向：Android backend → config/crypto/util，不反向依赖；JNI 桥是唯一的跨语言边界。
